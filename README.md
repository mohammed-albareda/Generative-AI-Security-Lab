# Defensive-Ransomware-Analysis-Lab 🚀

A powerful, modern desktop AI assistant built with Python and Tkinter. This project started as a simple Telegram bot and evolved into a full-featured desktop application with persistent chat history and context-aware memory.

---

## ✨ Features (Version 2.4)
- 🧠 **Context Memory**: Remembers previous messages in the session for accurate follow-up responses.
- 💾 **Persistent History**: Automatically saves your chats to `chats.json`.
- 🗂️ **Multi-Chat Management**: Sidebar to switch between different chat sessions or create new ones.
- 💻 **Code Blocks**: Beautiful code formatting with a dedicated "Copy Code" button.
- 🇷🇹 **Arabic RTL Support**: Fully optimized for Arabic text alignment (Right-to-Left).
- 📋 **Usability**: Support for Copy/Paste, Touchpad scrolling, and Context menus.
- ⚙️ **Customizable**: Settings panel to change font sizes and manage data.

---

## 🛠️ Technology Stack
- **Python 3.13**
- **Tkinter**: GUI Framework.
- **PyInstaller**: For building standalone EXEs.
- **Requests**: For AI API communication.

---

## 📁 Repository Structure
- `WormGPT_Desktop.py`: Main source code for the Desktop GUI.
- `WormGPT_Telegram_Bot.py`: Original Telegram Bot version (Simplified).
- `requirements.txt`: Python dependencies.
- `dist/WormGPT_Ultimate.exe`: The standalone Windows executable.
- `EXE_GUIDE.md`: Full guide on how to run and distribute the EXE.

---

## 🚀 How to Run
### 1. Standalone (Recommended)
Just download and run `dist/WormGPT_Ultimate.exe`. No installation required!

### 2. From Source
```bash
git clone (https://github.com/775503801)
cd worm_gpt_app
pip install -r requirements.txt
python WormGPT_Desktop.py
```
